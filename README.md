# txtboxgen
## Generates a textbox, you can make it a error, information, etc.

**It's a simple concept.**
"You could do this thru a .vbs!!! Bro just making anything!!!!!"

Well you could.. but who wants to do that? This script just gathers everything in 1.

# You will need to ``pip install`` these to make the script work!
```
pip install tkinter
```

# How to install?
**Clone this repository then open your terminal in the project directory and run the command to get all required libraries, after that, you can run python boxgen.py in the project directory.**
**..or you could use the .exe in the Releases.**
